## Description

SVG QR Code Generator bringt einen QR-Code-Generator für SVG in die Seitenleiste Ihres Browsers. Öffnen Sie die Seitenleiste, und der Code für die aktuelle Seite ist schon da: Halten Sie die Handykamera darauf, und dieselbe Seite öffnet sich auf dem Smartphone – ohne Link, den Sie sich selbst schicken müssen, und ohne Konto. Jeder Code wird direkt in Ihrem Browser als gestochen scharfes SVG gezeichnet.

Eine Seite aufs Handy schicken
• Sie lesen am Computer einen Artikel, ein Rezept oder eine Karte? Öffnen Sie die Seitenleiste und scannen Sie den Code mit dem Handy, um dort weiterzumachen.
• Sie testen eine Website im lokalen Netzwerk? Rufen Sie sie über die Netzwerkadresse des Computers auf, dann führt der Code Ihr Handy direkt dorthin.
• Das Handy öffnet nur, was es erreichen kann: Eine Adresse, die nur Ihr Computer kennt, etwa localhost, öffnet sich dort nicht.

Ein Code für alles
• Wechseln Sie zu „Eigener Text“, um einen beliebigen Text oder Link zu codieren – nicht nur die Seitenadresse.
• Wählen Sie eine von vier Größen und eine Fehlerkorrekturstufe von L bis H. Eine höhere Stufe hilft, dass ein gedruckter Code auch mit Kratzern oder Schmutz lesbar bleibt.
• Laden Sie das SVG herunter oder kopieren Sie das Markup. Der Code für einen Kurzlink ist nur wenige Kilobyte groß: ein einziger Pfad, scharf in jeder Größe, bereit für Druck, Präsentationen und Designprogramme.

Teilen und einbetten
• Kopieren Sie einen Freigabelink: Das Bild wird auf qr.clx.cx allein aus dem Link neu erzeugt und funktioniert daher ohne Konto und ohne gespeicherte Datei.
• Der Tab „Einbetten“ liefert ein fertiges Snippet für HTML, Markdown, React oder Vue.
• „Link kopieren“ speichert den Code außerdem im Verlauf auf Ihrem Gerät, wo Sie ihn jederzeit wieder kopieren oder öffnen können.

Datenschutz von Anfang an
• Die Erweiterung selbst stellt keine Netzwerkanfragen: Vorschau, SVG und Verlauf bleiben im Browser.
• Ein Freigabelink enthält den codierten Text im Klartext, daher kann ihn jeder lesen, der den Link hat. Passwörter gehören nicht in Codes, die Sie teilen.
• Keine Konten, keine Analyse, keine Werbung.
