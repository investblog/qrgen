## Description

SVG QR Code Generator installe un générateur de QR codes SVG dans le panneau latéral de votre navigateur. Ouvrez le panneau : le code de la page affichée est déjà là. Visez-le avec l’appareil photo de votre téléphone et la même page s’ouvre sur le mobile, sans vous envoyer de lien et sans compte. Chaque code est dessiné directement dans votre navigateur, en SVG bien net.

Envoyer une page sur votre téléphone
• Vous lisez un article, une recette ou une carte sur l’ordinateur ? Ouvrez le panneau et scannez le code avec votre téléphone pour continuer dessus.
• Vous testez un site sur votre réseau local ? Ouvrez-le via l’adresse réseau de l’ordinateur, et le code y mène directement votre téléphone.
• Le téléphone n’ouvre que ce qu’il peut joindre : une adresse connue de votre seul ordinateur, comme localhost, ne s’y ouvrira pas.

Un code pour tout
• Passez en « Texte libre » pour encoder n’importe quel texte ou lien, pas seulement l’adresse de la page.
• Choisissez l’une des quatre tailles et un niveau de correction d’erreurs de L à H. Un niveau plus élevé aide un code imprimé à rester lisible s’il est rayé ou taché.
• Téléchargez le SVG ou copiez son balisage. Le code d’un lien court ne pèse que quelques kilo-octets : un seul tracé, net à toutes les tailles, prêt pour l’impression, les présentations et les outils de design.

Partager et intégrer
• Copiez un lien de partage : l’image est reconstruite sur qr.clx.cx à partir du lien lui-même, elle fonctionne donc sans compte ni fichier stocké.
• L’onglet Intégrer vous donne un snippet prêt à l’emploi pour HTML, Markdown, React ou Vue.
• « Copier le lien » enregistre aussi le code dans l’Historique de votre appareil, prêt à être recopié ou rouvert.

Confidentiel par conception
• L’extension elle-même n’envoie aucune requête réseau : l’aperçu, le SVG et votre historique restent dans le navigateur.
• Un lien de partage contient le texte encodé en clair : toute personne qui a le lien peut le lire. Ne mettez pas de mots de passe dans les codes que vous partagez.
• Pas de compte, pas de statistiques, pas de publicité.

Besoin de savoir combien de personnes ont scanné un code ? Mettez-y un lien court clx.cx.

Panneau latéral dans Chrome et Edge, barre latérale dans Firefox, thèmes clair et sombre. L’interface suit la langue de votre navigateur et existe en sept langues.
