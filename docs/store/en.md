## Description

SVG QR Code Generator puts a QR code maker in your browser's side panel. Open the panel and the code for the page you are on is already there: point your phone's camera at it and the same page opens on the phone, with no link to send yourself and no account. Every code is drawn right in your browser as a crisp SVG.

Send a page to your phone
• Reading an article, a recipe or a map on your computer? Open the panel and scan the code with your phone to carry on there.
• Testing a site on your local network? Open it by the computer's network address, and the code takes your phone straight to it.
• The phone opens what it can reach: an address only your computer knows, such as localhost, will not open there.

Make a code for anything
• Switch to custom input to encode any text or link, not just the page address.
• Choose one of four sizes and an error correction level from L to H. A higher level helps a printed code stay readable when it gets scratched or smudged.
• Download the SVG or copy its markup. A code for a short link weighs a few kilobytes: one path, sharp at any size, ready for print, slides and design tools.

Share and embed
• Copy a share link: the image is rebuilt from the link itself on qr.clx.cx, so it keeps working with no account and no stored file.
• The Embed tab gives you a ready snippet for HTML, Markdown, React or Vue.
• Copy Share Link also saves the code in History on your device, ready to copy or open again.

Private by design
• The extension itself makes no network requests: the preview, the SVG and your history stay in the browser.
• A share link carries the encoded text in plain form, so anyone who has the link can read it. Keep passwords out of the codes you share.
• No accounts, no analytics, no ads.

Need to know how many people scanned a code? Put a short link from clx.cx into it.

Side panel in Chrome and Edge, sidebar in Firefox, light and dark themes. The interface follows your browser's language and is available in seven languages.

Made by 301.st. The source code is open: github.com/investblog/qrgen
