## Description

SVG QR Code Generator coloca um gerador de QR code em SVG no painel lateral do seu navegador. Abra o painel e o código da página em que você está já aparece: aponte a câmera do celular e a mesma página abre no telefone, sem precisar mandar o link para si mesmo e sem conta. Cada código é desenhado no próprio navegador como um SVG nítido.

Mande uma página para o celular
• Lendo um artigo, uma receita ou um mapa no computador? Abra o painel e escaneie o código com o celular para continuar por lá.
• Testando um site na rede local? Abra-o pelo endereço de rede do computador e o código leva o celular direto até ele.
• O celular só abre o que consegue acessar: um endereço que só o seu computador conhece, como localhost, não vai abrir nele.

Um código para qualquer coisa
• Mude para “Texto livre” para codificar qualquer texto ou link, não só o endereço da página.
• Escolha um de quatro tamanhos e um nível de correção de erros de L a H. Um nível mais alto ajuda um código impresso a continuar legível quando fica arranhado ou manchado.
• Baixe o SVG ou copie a marcação. O código de um link curto pesa poucos kilobytes: um único caminho, nítido em qualquer tamanho, pronto para impressão, slides e ferramentas de design.

Compartilhe e incorpore
• Copie um link de compartilhamento: a imagem é recriada no qr.clx.cx a partir do próprio link, então funciona sem conta e sem arquivo armazenado.
• A aba Código entrega um snippet pronto para HTML, Markdown, React ou Vue.
• “Copiar link” também salva o código no Histórico do seu dispositivo, pronto para copiar ou abrir de novo.

Privacidade desde o início
• A extensão em si não faz nenhuma requisição de rede: a prévia, o SVG e o seu histórico ficam no navegador.
• Um link de compartilhamento leva o texto codificado de forma legível, então qualquer pessoa com o link pode lê-lo. Não coloque senhas nos códigos que você compartilha.
• Sem contas, sem análises, sem anúncios.

Quer saber quantas pessoas escanearam um código? Use dentro dele um link curto do clx.cx.

Painel lateral no Chrome e no Edge, barra lateral no Firefox, temas claro e escuro. A interface segue o idioma do seu navegador e está disponível em sete idiomas.
