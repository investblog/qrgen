## Description

SVG QR Code Generator — генератор QR-кодов в боковой панели браузера. Откройте панель, и код страницы, на которой вы находитесь, уже готов: наведите на него камеру телефона, и та же страница откроется на телефоне — без пересылки ссылки самому себе и без аккаунта. Каждый код рисуется прямо в браузере, в чёткий SVG.

Страница — на телефон
• Читаете статью, рецепт или карту на компьютере? Откройте панель и отсканируйте код телефоном, чтобы продолжить уже на нём.
• Проверяете сайт в домашней сети? Откройте его по сетевому адресу компьютера, и код сразу приведёт туда телефон.
• Телефон откроет то, до чего может дотянуться: адрес, который знает только ваш компьютер, например localhost, на нём не откроется.

Код для чего угодно
• Переключитесь на «Свой текст», чтобы закодировать любой текст или ссылку, а не только адрес страницы.
• Выберите один из четырёх размеров и уровень коррекции ошибок от L до H. Чем выше уровень, тем больше шансов, что поцарапанный или затёртый печатный код прочитается.
• Скачайте SVG или скопируйте его разметку. Код короткой ссылки весит несколько килобайт: один контур, чёткий в любом размере, готов для печати, слайдов и графических редакторов.

Поделиться и встроить
• Скопируйте ссылку: картинка собирается из самой ссылки на qr.clx.cx, поэтому работает без аккаунта и без хранимого файла.
• На вкладке «Код» готов сниппет для HTML, Markdown, React или Vue.
• Кнопка «Скопировать ссылку» заодно сохраняет код в истории на вашем устройстве — его можно снова скопировать или открыть.

Приватность по умолчанию
• Само расширение не делает сетевых запросов: превью, SVG и история остаются в браузере.
• Ссылка содержит закодированный текст в открытом виде, и прочитать его может любой, у кого она есть. Не кладите пароли в коды, которыми делитесь.
• Без аккаунтов, без аналитики, без рекламы.

Хотите знать, сколько людей отсканировали код? Поместите в него короткую ссылку clx.cx.

Боковая панель в Chrome и Edge, боковая колонка в Firefox, светлая и тёмная темы. Интерфейс следует языку браузера и доступен на семи языках.
