# SVG QR Code Generator — листинг AMO, русский

Только для Firefox Add-ons: свой текст в Markdown AMO, не текст Chrome Web Store. Правила: [README](../README.md).

## Description

**QR-код открытой страницы — в боковой колонке Firefox.** Нажмите кнопку на панели инструментов, и SVG QR Code Generator покажет код текущей вкладки. Отсканируйте его камерой телефона и продолжайте читать там: не нужно слать себе ссылки по почте, включать синхронизацию или регистрироваться. Коды рисуются локально, в аккуратный SVG.

**С компьютера на телефон**

- Колонка открывается с текущей страницей, поэтому перенести её на телефон — одно сканирование.
- Подойдёт и сервер разработки в локальной сети: откройте его по IP-адресу компьютера и отсканируйте.
- Откроются только адреса, доступные телефону; localhost и другие имена, известные лишь вашему компьютеру, — нет.

**Создание кодов**

- Вместо адреса страницы можно ввести любой текст или ссылку.
- Четыре готовых размера и четыре уровня коррекции ошибок; с Q или H печатный код лучше переносит царапины.
- Сохраните код SVG-файлом или скопируйте разметку: один контур, несколько килобайт, чёткость в любом масштабе.

**Ссылки и встраивание**

- Ссылка на qr.clx.cx собирает картинку из самой ссылки при каждом открытии, поэтому файл картинки нигде не хранится.
- Сниппеты для HTML, Markdown, React и Vue — в один клик.
- Коды, скопированные кнопкой «Скопировать ссылку», попадают в историю и хранятся только на этом компьютере.

**Приватность**

- Дополнение само не делает сетевых запросов.
- Всё, что вы закодировали, прочитает любой, к кому попадёт ссылка, поэтому секретам там не место.
- Без регистрации, аналитики и рекламы.

Нужна статистика сканирований? Поместите в код короткую ссылку [clx.cx](https://ru.clx.cx/short-links).

Сделано в 301.st, исходный код открыт на [GitHub](https://github.com/investblog/qrgen). Светлая и тёмная темы; интерфейс следует языку вашего Firefox, всего семь языков.
