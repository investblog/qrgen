# SVG QR Code Generator — página no AMO, português (Brasil)

Só para Firefox Add-ons: um texto próprio no Markdown do AMO, diferente do da Chrome Web Store. Regras: [README](../README.md).

## Description

**Um QR code da página que você está lendo, na barra lateral do Firefox.** Clique no botão da barra de ferramentas e o SVG QR Code Generator mostra o código da aba atual. Escaneie com a câmera do celular e continue por lá: nada de mandar links para o próprio e-mail, sem sincronização, sem cadastro. Este gerador de QR code em SVG desenha cada código localmente, em vetor limpo.

**Do computador para o celular**

- A barra lateral já começa com a página atual, então levá-la para o celular é questão de um único escaneamento.
- Um servidor de desenvolvimento na rede local também funciona: abra pelo IP do computador e escaneie.
- Só abrem endereços que o celular alcança; localhost e outros nomes que só o seu computador conhece não abrem.

**Criando códigos**

- Digite qualquer texto ou link no lugar do endereço da página.
- Quatro tamanhos predefinidos e quatro níveis de correção de erros; com Q ou H, um código impresso aguenta melhor os arranhões.
- Salve o código como arquivo SVG ou copie a marcação: um só caminho, poucos kilobytes, nítido em qualquer escala.

**Compartilhando e incorporando**

- Um link de compartilhamento no qr.clx.cx recria a imagem a partir do próprio link sempre que é aberto, então nenhum arquivo de imagem fica armazenado.
- Snippets para HTML, Markdown, React e Vue a um clique de distância.
- Os códigos que você copia com “Copiar link” vão para o Histórico, guardado só neste computador.

**Privacidade**

- A extensão não faz nenhuma requisição de rede por conta própria.
- Tudo o que você codifica pode ser lido por quem receber o link de compartilhamento, então deixe segredos de fora.
- Sem cadastro, sem análises, sem anúncios.

Quer contar escaneamentos? Coloque um link curto do [clx.cx](https://clx.cx/short-links) dentro do código.

Por 301.st, código aberto no [GitHub](https://github.com/investblog/qrgen). Temas claro e escuro; a interface acompanha o idioma do seu Firefox, em sete idiomas.
