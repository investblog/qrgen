Tips

  • Click the toolbar icon to open the side panel; pin the icon to keep it at hand.
  • Switch to “Custom input” to encode any text, not just the page address.
  • Error correction Q or H keeps a printed code readable when it gets scratched.
  • Every code whose link you copied stays in History, on your device only.
